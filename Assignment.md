Assignment 3 – Terminal Navigation Practice Sheet
1. Objective -
To learn basic terminal commands for navigating folders and files.
Hindi: Terminal commands ki help se folders aur files ko open karna, dekhna aur navigate karna seekhna.
2. What is a Terminal?
A terminal is a text-based interface used to communicate with a computer using commands.
Hindi: Terminal ek aisi jagah hai jahan hum commands likhkar computer ko instructions dete hain.
3. Basic Terminal Commands
1. pwd – Print Working Directory
2. mkdir – Make Directory
It creates a new folder.
Example:
mkdir MyFolder
clear
7. touch – Create a File
It creates an empty file in Linux/macOS/Git Bash.
Example:
touch index.html
4. Practice Tasks
Perform the following tasks in your terminal:
Display the current directory using pwd.
List all files and folders using ls.
Create a folder named Practice using mkdir.
Enter the Practice folder using cd Practice.
Display the current location using pwd.
Go back to the previous folder using cd ...
Clear the terminal screen using clear.
